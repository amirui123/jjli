# آزمایشگاه موشن فارسی — RTL Motion Lab

پلتفرم ۱۰۰٪ رایگان و متن‌باز مهندسی رابط فارسی: استودیوهای مستقل برای تایپوگرافی،
فیزیک حرکت، کامپوننت‌ها، صدا، مهارت‌ها، موتورهای بومی و هوش مصنوعی.

> بدون ثبت‌نام، بدون سطح پولی، بدون سرور — همه محاسبات در مرورگر.

---

## صفحات (مسیرهای مستقل)

| مسیر | صفحه | محتوا |
| --- | --- | --- |
| `#/` | معرفی | هیروی جنبشی با فونت هستی/نستعلیق، آمار واقعی، مارکی اسکیل‌ها، ویترین فونت و استودیوها |
| `#/dashboard` | داشبورد | کارت همه بخش‌ها با پیش‌نمایش زنده، تنظیمات سریع، نقشه رجیستری‌ها |
| `#/studio/fonts` | استودیو فونت | ۴۰ خانواده، کنترل وزن/اندازه/فاصله/چیدمان، مقایسه، خروجی CSS · Tailwind · React · next/font |
| `#/studio/motion` | استودیو موشن | شبیه‌سازی عددی فنر، منحنی زمان، نسبت میرایی، خروجی Motion · CSS `linear()` · Variants |
| `#/studio/components` | استودیو کامپوننت | ۴٬۱۹۷ فایل واقعی در ۱۲ رجیستری + پیش‌نمایش‌های زنده |
| `#/studio/sounds` | استودیو صدا | ۲۰۰ افکت سینتز، شکل موج واقعی (رندر آفلاین)، خروجی WAV |
| `#/studio/skills` | استودیو مهارت | ۱۷۹ `SKILL.md` و ۸۴ `DESIGN.md`، پرامپت‌ساز، اعمال پالت برند |
| `#/studio/engines` | استودیو موتور | فین‌تک ایران (۱۸ بانک، شبا، کد ملی، عدد به حروف)، ممیز RTL، شیدرها |
| `#/studio/ai` | استودیو هوش مصنوعی | دیتاست QLoRA، پرامپت‌ساز تخصصی، پیکربندی آموزش |

ناوبری پایین صفحه (Dock) بین همه بخش‌ها جابه‌جا می‌شود؛ همه مسیرها hash-based هستند و
روی هر هاست استاتیکی کار می‌کنند.

## دستورها

```bash
npm install
npm run dev        # تولید داده + اجرای Vite روی 0.0.0.0:5173
npm run build      # تولید داده + بیلد پروداکشن در dist/
npm run serve      # سرور استاتیک پروداکشن (brotli/gzip) روی 0.0.0.0:5173
npm run typecheck  # بررسی کامل TypeScript
node scripts/smoke-test.mjs  # تست دود واقعی در jsdom روی همه مسیرها
```

## معماری

```
src/
  shell/AppShell.tsx      نوار بالا، جستجوی سریع (⌘K)، داک پایین، فوتر
  lib/router.tsx          روتر hash بدون وابستگی
  lib/store.tsx           تنظیمات پایدار (localStorage)، تم، بارگذاری تنبل داده
  lib/spring.ts           فیزیک فنر واقعی + تولید easing و منحنی
  ui/kit.tsx              کیت رابط (Panel, Slider, Toggle, CodeBlock, ...)
  ui/Markdown.tsx         رندر سبک SKILL.md / DESIGN.md
  pages/*.tsx             یک فایل برای هر استودیو (lazy-loaded)
  data/                   مانيفست‌های تولیدشده (کامپوننت، فونت، صدا، اسکیل)
  engines/                موتور صدا (Web Audio) و موتورهای فارسی/RTL
```

### داده واقعی

| منبع | تعداد | محل |
| --- | --- | --- |
| فایل کامپوننت | ۴٬۱۹۷ در ۱۲ رجیستری | `public/regcode/*.json` (بارگذاری تنبل) |
| اسکیل | ۱۷۹ | `public/vault/skills/*.md` |
| سیستم برند | ۸۴ | `public/vault/brands/*.md` |
| فونت فارسی | ۴۰ خانواده | `public/fonts/` + `src/index.css` |
| افکت صوتی | ۲۰۰ | `src/data/soundsManifest.ts` |
| جفت دیتاست | ۴۰ | `public/ai/dataset.json` |

داده‌ها با `npm run generate` از پوشه `toolkit/` بازتولید می‌شوند. اگر `toolkit/`
موجود نباشد، اسکریپت‌ها داده‌های کامیت‌شده را دست نمی‌زنند.

## عملکرد

- هر صفحه lazy-load است؛ باندل ورودی ~۱۰۴KB (gzip) و هر استودیو ۵ تا ۵۹KB.
- فهرست‌های بزرگ (۴٬۱۹۷ فایل، ۲۰۰ صدا) با windowing مجازی رندر می‌شوند.
- شیدرها با `IntersectionObserver` و `visibilitychange` متوقف می‌شوند؛ DPR حداکثر ۲.
- تصاویر/فونت‌ها با `font-display: swap` و preload برای دو فونت اصلی.
- `prefers-reduced-motion` و تنظیم «شدت حرکت» در کل پلتفرم اعمال می‌شود.

## دسترس‌پذیری

RTL کامل، `aria-label` فارسی روی کنترل‌ها، فوکوس‌رینگ واضح، کنتراست بالا و
احترام به کاهش حرکت.
