# آزمایشگاه موشن فارسی — RTL Motion Lab

پلتفرم **کاملاً رایگان** و متن‌باز برای ساخت رابط‌های فارسی: تایپوگرافی، فیزیک حرکت،
کامپوننت‌های واقعی، صداهای رویه‌ای و موتورهای بومی. بدون حساب کاربری، بدون سطح پولی و
بدون سرور — همه‌چیز در مرورگر اجرا می‌شود.

```
خروجی واقعی · چند صفحه‌ای · RTL-first · ۱۰۰٪ آفلاین‌پذیر
```

`React.lazy` تقسیم شده‌اند تا هر بخش فقط کد خودش را دانلود کند.

### معرفی (Intro)

بار اول، یک فیلم کوتاه پنج‌صحنه‌ای پیش از ورود پخش می‌شود: کاور واژه‌به‌واژه،
نمونه‌های فونت، منحنی فنر، شکل موج صدا و شیدر زنده. دو نسخه مستقل دارد —
دسکتاپ (صحنه بزرگ + ریل صحنه‌ها) و موبایل (کارت عمودی قابل کشیدن) — با کنترل
توقف/رد کردن، ناوبری کلیدی و احترام کامل به `prefers-reduced-motion`.
از دکمهٔ 🎬 در نوار بالا هر وقت خواستید دوباره پخش می‌شود.

### روی موبایل

هر استودیو در موبایل به سه **تب** تبدیل می‌شود — «پیش‌نمایش / تنظیمات / فهرست» —
تا برای رسیدن به هر پنل لازم نباشد صفحه را تا انتها اسکرول کنید. با انتخاب هر
آیتم از فهرست، خودکار به پیش‌نمایش برمی‌گردید و نتیجه را همان‌جا می‌بینید.
لمس‌ها حداقل ۴۰ پیکسل، ورودی‌ها ۱۶ پیکسل (بدون زوم iOS) و داک پایین با
`env(safe-area-inset-bottom)` برای آیفون‌های نوار‌دار تنظیم شده‌اند.

### استودیوهای مشترک (تک‌صفحه‌ای)

هر بخش یک **صفحه کامل و مستقل** است که در دسکتاپ کل ارتفاع دید را می‌گیرد و
هیچ‌گاه اسکرول صفحه ندارد:

```
[ تنظیمات کامل ]   [ پیش‌نمایش زنده ]   [ فهرست همه آیتم‌ها ]
        چپ                   وسط                  راست
```

هر ریل (**فهرست**، **پیش‌نمایش**، **تنظیمات**) اسکرول داخلی خودش را دارد، بنابراین
پیش‌نمایش همیشه در دید می‌ماند و نیازی به رفت‌وبرگشت عمودی نیست.

- **عرض ریل‌ها قابل تغییر است**: دو جداکنندهٔ عمودی را بکشید (یا با کلیدهای جهت‌دار
  وقتی فوکوس دارند جابه‌جا کنید). دوبار کلیک = بازگشت به عرض پیش‌فرض. عرض‌ها ذخیره می‌شوند.
- **حالت تمرکز**: کلید `F` هر دو ریل را پنهان می‌کند و پیش‌نمایش تمام عرض را می‌گیرد؛
  `Esc` برمی‌گرداند.
- زیر ۱۲۰۰ پیکسل ریل‌ها روی هم می‌چینند و صفحه به‌شکل عادی اسکرول می‌شود. تنظیمات هر استودیو در
`localStorage` ذخیره و روی پیش‌نمایش، اعداد و کد خروجی اعمال می‌شوند.


داده‌های موجود را دست‌نخورده رها می‌کنند.

## ویژگی‌های مهندسی

- **بدون سرور:** تشخیص بانک، اعتبارسنجی شبا/کد ملی، تبدیل عدد به حروف، پاک‌ساز
  نیم‌فاصله، ممیزی RTL و سینتز ۲۰۰ افکت همه سمت کلاینت.
- **دانلود واقعی:** فایل فونت، `.tsx` هر کامپوننت، `.wav` صدای سینتزشده،
  سند `.md` مهارت و ZIP کیت کامل.
- **عملکرد:** صفحه‌ها lazy، فهرست ۴٬۱۸۸ فایلی با مجازی‌سازی، جستجو با debounce،
  شیدرها با توقف خودکار خارج از دید، فونت‌ها با `font-display: swap`.
- **دسترسی‌پذیری:** `prefers-reduced-motion`، حالت فوکوس واضح، `aria-label` فارسی،
  کنتراست محاسبه‌شده.
- **RTL:** فقط کلاس‌های منطقی (`ms/me/ps/pe/start/end`)، ارقام فارسی، بدون
  `letter-spacing` مثبت روی متن؛ ۲۰ قاعده ممیزی که هم تشخیص می‌دهد و هم اصلاح می‌کند.
- **تک‌فایلی:** `share/rtl-motion-lab-standalone.html` همه فونت‌ها را base64 در خود
  دارد و بدون هیچ درخواست شبکه‌ای باز می‌شود (فقط برای فرستادن به دیگران؛ روی سایت
  منتشر نمی‌شود).

## نسخهٔ تک‌فایلی کامل (برای فرستادن به دیگران)

`npm run single` خروجی می‌سازد: `share/rtl-motion-lab-standalone.html`

این فایل **خودِ اپلیکیشن** است، نه یک دموی جدا: همان کامپوننت‌ها، همان CSS، همان
فونت‌ها و همان رفتار. با بازکردن فایل روی موبایل یا دسکتاپ — حتی بدون اینترنت —
دقیقاً همان چیزی را می‌بینید که در نسخهٔ آنلاین هست.

چه چیزهایی داخل فایل است:

- کل جاوااسکریپت و CSS اپ در یک باندل (بدون chunk جداگانه؛ `vite.single.config.ts`)
- هر فایل `public/`: ۹۷ فایل فونت، آرشیو ۴٬۱۹۹ کامپوننت، vault مهارت/برند، دادهٔ استودیوی هوش مصنوعی
  (متن‌ها gzip می‌شوند، فونت‌ها خام می‌مانند)
- یک شبیه‌ساز `fetch` که همان مسیرهای اپ (`/vault/...`، `/regcode/...`، `/fonts/...`، `/ai/...`)
  را از حافظه سرو می‌کند، پس روی `file://` هم دانلود فونت، متن کامپوننت و WAV کار می‌کند
- `@font-face` ها هنگام بوت از همان داده ساخته می‌شوند تا فونت‌ها دو بار در فایل ذخیره نشوند

حجم: حدود ۲۳ مگابایت. برای بازکردن به مرورگر مدرن نیاز دارد (Chrome/Edge 80+،
Firefox 113+، Safari 16.4+؛ دلیلش `DecompressionStream` است). روی مرورگر قدیمی،
بخش‌های آرشیو/vault داده نشان نمی‌دهند ولی بقیهٔ اپ کار می‌کند.

راه فرستادن:

- تلگرام / بله / ایتا / واتساپ → «ارسال به‌صورت فایل» و انتخاب همین HTML
- اگر پیام‌رسان پسوند html را بلوکه کرد، فایل را داخل ZIP بگذارید یا نامش را به `.txt` تغییر دهید
  و به گیرنده بگویید بعد از دانلود پسوند را به `.html` برگرداند
- ایمیل معمولی برای ۲۳ مگابایت مناسب نیست (پس از کدگذاری از سقف ۲۵ مگابایت می‌گذرد)؛
  از Google Drive یا لینک مستقیم استفاده کنید

## انتشار روی GitHub Pages (سرورهای خود گیت‌هاب)

ورک‌فلوی `.github/workflows/pages.yml` اپ را با `VITE_BASE=/<repo>/` می‌سازد و روی
GitHub Pages منتشر می‌کند؛ نتیجه بدون محافظت و لاگین برای همه باز می‌شود و کاری به
Deployment Protection ورسل ندارد.

تنها یک صفحه منتشر می‌شود: خود اپ. `dist/index.html` به‌عنوان `dist/404.html` هم کپی
می‌شود تا مسیرهای هش‌دار (`#/studio/fonts`) و آدرس‌های ناشناخته هر دو اپ را بوت کنند.
خروجی تک‌فایلی آفلاین (`share/`) هیچ‌وقت روی سایت کپی نمی‌شود؛ فقط خود اپ منتشر می‌شود.

**جریان انتشار:** روی هر push به `main` خودکار اجرا می‌شود
(`npm ci` → `npm run build` با `VITE_BASE=/jjli/` → آپلود آرتیفکت → deploy). محیط
`github-pages` تنها شاخهٔ `main` را می‌پذیرد، پس تغییرات با PR از شاخهٔ کاری به `main`
می‌رسند و بعد خودکار منتشر می‌شوند. (توکن ربات اجازهٔ تغییر همین تنظیم را ندارد؛ در
Settings → Environments → github-pages می‌توانید شاخهٔ دیگری را هم مجاز کنید.)

فقط یک تنظیم یک‌باره لازم است (توکن ربات اجازهٔ آن را ندارد):
**Settings → Pages → Build and deployment → Source: GitHub Actions**

برای اینکه اپ از زیرمسیر `/jjli/` هم کار کند:

- `vite.config.ts` مقدار `VITE_BASE` را می‌خواند (پیش‌فرض `/`، پس Vercel دست‌نخورده است).
- `src/lib/base.ts` تابع `publicUrl()` را می‌دهد و همهٔ درخواست‌های زمان‌اجرا
  (`loadAsset`، `saveUrl`، `fetchAsBlob`) از آن رد می‌شوند. تست:
  `.smoke/base-path.mjs` — بیلد را روی `/jjli/` سرو می‌کند و مطمئن می‌شود هیچ
  درخواستی بدون پیشوند نرود.

## انتشار روی Vercel

پروژهٔ `rtl-motion-lab` با فریم‌ورک Vite، دستور ساخت `npm run build` و خروجی `dist`
(نشر آن پشت Deployment Protection است، پس آدرس عمومی پروژه همان GitHub Pages است).

سه نکته‌ای که باعث می‌شد بیلد روی سرور شکست بخورد و برای همیشه اصلاح شد:

- **مسیرهای نسبی:** اسکریپت‌های `generate` مسیر مخزن را از محل خودِ
  اسکریپت می‌سازند (`new URL("..", import.meta.url)`)، نه از یک مسیر مطلق. هر چک‌اوت در
  مسیر دیگر (مثل `/vercel/path0`) بدون تغییر کار می‌کند.
- **نسخهٔ Node:** `engines.node` و `.nvmrc` روی ۲۲ قفل شده‌اند؛ همان نسخه‌ای که بیلد و
  تست‌ها روی آن اجرا می‌شوند.
- **esbuild:** ایمیج‌های جدید npm اسکریپت نصب وابستگی‌ها را رد می‌کنند و باینری esbuild
  لینک نمی‌شود؛ `postinstall` (اسکریپت `scripts/ensure-esbuild.mjs`) وجود باینری را
  بررسی و در صورت نیاز نصب‌کنندهٔ خودِ esbuild را دوباره اجرا می‌کند.
