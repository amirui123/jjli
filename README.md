# آزمایشگاه موشن فارسی — RTL Motion Lab

پلتفرم **کاملاً رایگان** و متن‌باز برای ساخت رابط‌های فارسی: تایپوگرافی، فیزیک حرکت،
کامپوننت‌های واقعی، صداهای رویه‌ای و موتورهای بومی. بدون حساب کاربری، بدون سطح پولی و
بدون سرور — همه‌چیز در مرورگر اجرا می‌شود.

```
خروجی واقعی · چند صفحه‌ای · RTL-first · ۱۰۰٪ آفلاین‌پذیر
```

`React.lazy` تقسیم شده‌اند تا هر بخش فقط کد خودش را دانلود کند.

### استودیوهای مشترک (تک‌صفحه‌ای)

هر بخش یک **صفحه کامل و مستقل** است که در دسکتاپ کل ارتفاع دید را می‌گیرد و
هیچ‌گاه اسکرول صفحه ندارد:

```
[ تنظیمات کامل ]   [ پیش‌نمایش زنده ]   [ فهرست همه آیتم‌ها ]
        چپ                   وسط                  راست
```

هر ریل (**فهرست**، **پیش‌نمایش**، **تنظیمات**) اسکرول داخلی خودش را دارد، بنابراین
پیش‌نمایش همیشه در دید می‌ماند و نیازی به رفت‌وبرگشت عمودی نیست. زیر `xl` ریل‌ها
روی هم می‌چینند و صفحه به‌شکل عادی اسکرول می‌شود. تنظیمات هر استودیو در
`localStorage` ذخیره و روی پیش‌نمایش، اعداد و کد خروجی اعمال می‌شوند.

## اجرا

```bash
npm ci
npm run generate      # ساخت داده از toolkit/ (اگر موجود باشد)
npm run dev           # vite روی 0.0.0.0:5173
npm run build         # خروجی production در dist/
npm run serve         # سرور استاتیک با brotli + SPA fallback
npm run smoke         # تست دود واقعی با jsdom روی همه مسیرها
```

`toolkit/` (پیکره ۷۶ مگابایتی منابع) در مخزن نیست؛ داده‌های مشتق‌شده
(`src/data/*`, `public/regcode`, `public/vault`, `public/ai`) کامیت شده‌اند، بنابراین
`npm run build` بدون آن هم کار می‌کند. اسکریپت‌های تولید اگر `toolkit/` نبود،
داده‌های موجود را دست‌نخورده رها می‌کنند.

## ویژگی‌های مهندسی

- **بدون سرور:** تشخیص بانک، اعتبارسنجی شبا/کد ملی، تبدیل عدد به حروف، پاک‌ساز
  نیم‌فاصله، ممیزی RTL و سینتز ۲۰۰ افکت همه سمت کلاینت.
- **دانلود واقعی:** فایل فونت، `.tsx` هر کامپوننت، `.wav` صدای سینتزشده،
  سند `.md` مهارت و ZIP کیت کامل.
- **عملکرد:** صفحه‌ها lazy، فهرست ۴٬۱۸۸ فایلی با مجازی‌سازی، جستجو با debounce،
  شیدرها با توقف خودکار خارج از دید، فونت‌ها با `font-display: swap`.
- **دسترسی‌پذیری:** `prefers-reduced-motion`، حالت فوکوس واضح، `aria-label` فارسی،
  کنتراست محاسبه‌شده.
- **RTL:** فقط کلاس‌های منطقی (`ms/me/ps/pe/start/end`)، ارقام فارسی، بدون
  `letter-spacing` مثبت روی متن.
