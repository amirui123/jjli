# Superformula 3D Shape Categories

A reference of 3D supershape families generated by Gielis' superformula, with approximate parameter ranges and a sample configuration for each.

## The formula

$$
r(\varphi) = \left( \left| \frac{\cos\left(\frac{m\varphi}{4}\right)}{a} \right|^{n_2} + \left| \frac{\sin\left(\frac{m\varphi}{4}\right)}{b} \right|^{n_3} \right)^{-\frac{1}{n_1}}
$$

3D surfaces use the spherical product of two evaluations, r₁ (longitude θ ∈ [−π, π]) and r₂ (latitude φ ∈ [−π/2, π/2]):

```
x = r1(θ) · cos θ · r2(φ) · cos φ
y = r1(θ) · sin θ · r2(φ) · cos φ
z = r2(φ) · sin φ
```

- **Set 1** (r₁) controls the top-down cross-section.
- **Set 2** (r₂) controls the side profile.
- All configs below use **a = b = 1** and are written as **(m, n₁, n₂, n₃)**.

## Quick parameter guide

| Parameter | Effect | Typical range |
|---|---|---|
| m | Rotational symmetry (number of lobes/corners). 0 = circle. Non-integer = unclosed curve | 0 – 20 |
| n₁ | Global inflation. < 1 pinches sides inward (spikes); large values push toward convex polygons | 0.1 – 50 |
| n₂, n₃ | Shape of each lobe's two halves. Equal = symmetric lobes; unequal = lopsided lobes. ~1 = straight edges, ~2 = smooth, large = flat sides | 0.1 – 50 |
| a, b | Stretch cosine/sine terms; unequal values alternate fat and thin lobes | 0.5 – 2 (usually 1) |

## Categories

Ranges are approximate starting points — the shapes change continuously, so boundaries between categories are soft.

| Category | Set 1 range (m, n₁, n₂, n₃) | Set 2 range (m, n₁, n₂, n₃) | Sample config (Set 1 / Set 2) |
|---|---|---|---|
| **Spheres and blobs** | m = 0 (any n); or m = 4 with n₁ = n₂ = n₃ = 2 | same as Set 1 | (0, 1, 1, 1) / (0, 1, 1, 1) |
| **Rounded boxes** | m = 4; n₁ = n₂ = n₃ ≈ 3 – 8 | same as Set 1 | (4, 4, 4, 4) / (4, 4, 4, 4) |
| **Sharp cubes** | m = 4; n₁ = n₂ = n₃ ≈ 10 – 50 | same as Set 1 | (4, 20, 20, 20) / (4, 20, 20, 20) |
| **Diamonds and octahedra-like solids** | m = 4; n₁ = n₂ = n₃ ≈ 0.8 – 1.2 | same as Set 1 | (4, 1, 1, 1) / (4, 1, 1, 1) |
| **Cylinders** | m = 0 | m = 4; n₁ = n₂ = n₃ ≈ 10 – 50 | (0, 1, 1, 1) / (4, 20, 20, 20) |
| **Polygonal prisms** | m = 3 – 8; n₁ = n₂ = n₃ ≈ 10 – 50 | m = 4; n₁ = n₂ = n₃ ≈ 10 – 50 | (6, 20, 20, 20) / (4, 20, 20, 20) |
| **Stars and starfish** | m = 3 – 8; n₁ ≈ 0.1 – 0.5; n₂ = n₃ ≈ 0.1 – 1 | m = 0 – 2; n₁ ≈ 0.1 – 0.5; n₂ = n₃ ≈ 0.1 – 1 | (5, 0.3, 0.3, 0.3) / (1, 0.3, 0.3, 0.3) |
| **Flowers and petals** | m = 5 – 12; n₁ ≈ 0.1 – 0.4; n₂ = n₃ ≈ 1.5 – 2 | same as Set 1 | (7, 0.2, 1.7, 1.7) / (7, 0.2, 1.7, 1.7) |
| **Urchins and spiky balls** | m = 8 – 20; n₁ = n₂ = n₃ ≈ 0.2 – 0.6 | same as Set 1 | (12, 0.5, 0.5, 0.5) / (12, 0.5, 0.5, 0.5) |

## Practical notes

- **Clamp the radius.** When n₁ is very small or the inner sum approaches zero, r can blow up. Cap r (e.g. at 50) before scaling the mesh.
- **Normalize for display.** Divide all coordinates by the largest absolute coordinate so every shape fits the same view.
- **Watch for bad geometry.** Extreme values (n₁ < 0.15, very high m) create self-intersecting or razor-thin surfaces; smooth or repair the mesh before 3D printing.
- **Mesh resolution.** High m or spiky configs need finer sampling (e.g. 200+ steps in θ) to avoid jagged spikes.
- **Mixing sets.** Because the top view and side profile are independent, the most interesting results often come from pairing two different categories.
