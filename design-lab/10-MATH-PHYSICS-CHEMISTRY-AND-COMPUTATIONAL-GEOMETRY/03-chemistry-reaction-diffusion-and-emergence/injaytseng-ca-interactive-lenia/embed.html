<ca-background>

Six families of cellular automata as a living background for any page. One script tag, one element, no build step, no dependencies. The flock behind this text is it.

<script type="module" src="https://ca.davidyc.com/element.js"></script>
<ca-background sim="boids"></ca-background>

<style>
  ca-background { position: fixed; inset: 0; z-index: -1; }
</style>

Sizing is your page's job: the element is display: block and fills whatever box you give it. The CSS above is the full-page recipe. The element sets pointer-events: none, so everything on top of it stays clickable while the animation still follows the cursor.

Every attribute is live and mirrored as a property (el.sim = 'lenia'). One method: el.reseed(). One read-only property: el.current, the id of the sim actually running.

What it costs, what can fail

  • Tabs 01–04 (rule1d, life, cyclic, boids) are Canvas 2D and run everywhere. lenia and nca need WebGL2; nca also needs float render targets and fetches 85 KB of weights the first time it is shown.
  • When a sim cannot run, the element warns on the console and mounts fallback. If that fails too, it renders nothing and your own background shows through. It never throws into your page.
  • The loop stops while the tab is hidden and while the element is scrolled out of view.
  • Every module is served with Cache-Control: must-revalidate, so a page always gets a consistent set of files, and with Access-Control-Allow-Origin: *, so it works from any origin.
