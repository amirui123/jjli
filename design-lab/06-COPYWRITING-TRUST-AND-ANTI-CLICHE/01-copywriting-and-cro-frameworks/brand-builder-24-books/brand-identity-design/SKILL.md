# Brand Identity Design

You are an expert in visual brand identity design. When the user asks to create or refine a brand's visual identity, follow this structured approach. A brand identity is NOT just a logo — it's a complete visual system that communicates the brand's essence at every touchpoint.

## Step 1: Design Brief (From Brand Platform)

Before designing anything, establish the strategic foundation:

1. **Brand WHY** (from Golden Circle): What emotional core must the visuals communicate?
2. **Brand Archetype**: What visual personality does the archetype demand?
3. **Positioning**: What visual territory differentiates this brand from competitors?
4. **Target Audience**: What aesthetic resonates with the primary persona?
5. **Brand Values**: What values must be visible in the design?

## Step 2: Logo Design

### The Logo Design Process (David Airey — Logo Design Love)

1. **Research first**: Understand the brand, industry, competition, and audience before sketching
2. **Sketch broadly**: Generate 50+ rough concepts on paper before touching a computer
3. **Focus on simplicity**: A logo must work at 16px (favicon) and on a billboard
4. **Test in black and white**: If it doesn't work in monochrome, color won't save it
5. **Ensure distinctiveness**: Apply the "squint test" — still recognizable when blurry?

### Logo Quality Checklist
- [ ] Simple enough to describe in one sentence
- [ ] Works in one color (black on white)
- [ ] Scalable from favicon to billboard
- [ ] Distinct from competitors
- [ ] Relevant to the brand's industry/archetype
- [ ] Timeless (will it still work in 10 years?)
- [ ] Memorable (can you draw it from memory?)

### Logo Types
1. **Wordmark** (Logotype): Brand name in custom typography — Google, Coca-Cola
2. **Lettermark**: Initials — IBM, HBO, NASA
3. **Brandmark** (Symbol): Icon only — Apple, Nike, Twitter
4. **Combination Mark**: Symbol + wordmark — Adidas, Burger King
5. **Emblem**: Text inside a symbol — Starbucks, Harley-Davidson

### Which Logo Type to Choose?
- **New brand, unknown name**: Use combination mark (need the name visible)
- **Long brand name**: Consider lettermark or abbreviation
- **Aspirational/iconic brand**: Aim for brandmark (long-term goal)
- **Heritage/authority brand**: Emblem works well
- **Simple, modern brand**: Wordmark with distinctive typography

## Step 3: Color Palette

### Color Psychology (Universal Principles of Design + Brand and Design)

| Color | Associations | Best For |
|-------|-------------|----------|
| Red | Energy, passion, urgency, danger | Action brands, food, sport |
| Blue | Trust, calm, intelligence, stability | Finance, tech, healthcare |
| Green | Nature, growth, health, freshness | Eco, health, finance |
| Yellow | Optimism, warmth, caution, youth | Children, food, optimism |
| Orange | Creativity, enthusiasm, affordable | Retail, entertainment, youth |
| Purple | Luxury, mystery, spirituality, wisdom | Premium, beauty, education |
| Black | Power, elegance, sophistication, edge | Luxury, fashion, tech |
| White | Purity, simplicity, cleanliness | Healthcare, tech, minimalism |

### Building the Palette
1. **Primary color** (1): The brand's signature — used on logo, key CTAs, headers
2. **Secondary colors** (2-3): Complement the primary — used for accents, sections, categories
3. **Neutral colors** (2-3): Backgrounds, text, borders — greys, whites, near-blacks
4. **Accent/Alert colors** (1-2): Success, error, warning states

### Color Harmony Rules
- **Complementary**: Opposite on the color wheel (high contrast, energetic)
- **Analogous**: Adjacent on the color wheel (harmonious, calm)
- **Triadic**: Three equally spaced (balanced, vibrant)
- **60-30-10 Rule**: 60% dominant color, 30% secondary, 10% accent

### Accessibility Requirements
- Text contrast ratio: minimum 4.5:1 (AA) or 7:1 (AAA)
- Never rely on color alone to convey meaning
- Test for color blindness (protanopia, deuteranopia, tritanopia)

## Step 4: Typography

### Typography Selection (Wheeler + Universal Principles of Design)

**Primary typeface** — Used for headings, brand name, key messages
- Must reflect the brand personality
- Should have multiple weights (light, regular, bold, extra bold)

**Secondary typeface** — Used for body text, UI, long-form content
- Must be highly legible at small sizes
- Should complement (not compete with) the primary typeface

### Pairing Rules
1. **Contrast is key**: Pair a serif with a sans-serif (not two serifs or two sans-serifs)
2. **Similar x-height**: Ensures visual harmony when used together
3. **Shared era/mood**: Both should feel like they belong to the same brand world
4. **Maximum 2-3 typefaces**: More = visual chaos

### Typography Hierarchy
- **H1**: Brand statements, hero text (primary typeface, bold, large)
- **H2**: Section headers (primary typeface, medium weight)
- **H3**: Subsection headers (primary or secondary, semi-bold)
- **Body**: Long-form content (secondary typeface, regular, 16-18px base)
- **Caption**: Metadata, labels (secondary typeface, light, smaller)

## Step 5: Design System Components

### Brand Touchpoints (Wheeler — Designing Brand Identity)

Map the visual identity across all touchpoints:

**Digital**:
- Website/App: UI colors, typography, button styles, iconography
- Social media: Profile images, post templates, story templates
- Email: Header design, signature, newsletter template

**Print**:
- Business cards, letterhead, envelopes
- Brochures, flyers, posters
- Packaging (if applicable)

**Environmental**:
- Signage, vehicle wraps, trade show displays
- Office/store interior design elements

### Iconography Style
Match icon style to brand archetype:
- **Filled icons**: Bold, confident (Hero, Ruler)
- **Outlined icons**: Light, modern (Sage, Creator)
- **Rounded icons**: Friendly, approachable (Caregiver, Everyman)
- **Duotone icons**: Layered, premium (Magician, Lover)

### Photography/Imagery Style
Define the visual tone for brand imagery:
- Subject matter: People, products, landscapes, abstract?
- Lighting: Natural, studio, dramatic, soft?
- Color treatment: Full color, muted, high contrast, duotone?
- Composition: Rule of thirds, centered, asymmetric?
- Mood: Authentic and candid vs. polished and aspirational?

## Step 6: Brand Guidelines Document

### Neumeier's Swap Test
Cover the logo on any brand touchpoint. Can you still identify the brand? If not, the identity system isn't distinctive enough.

### Minimum Brand Guidelines Structure
```
# [Brand Name] — Brand Guidelines

## 1. Brand Overview
- Mission/Vision/WHY
- Brand archetype and personality

## 2. Logo
- Primary logo (full color, reversed, monochrome)
- Logo variations (horizontal, stacked, icon-only)
- Clear space and minimum size rules
- Logo misuse examples (what NOT to do)

## 3. Color Palette
- Primary, secondary, neutral, accent colors
- Hex, RGB, CMYK, Pantone values
- Color usage ratios and rules

## 4. Typography
- Primary and secondary typefaces
- Hierarchy and sizing scale
- Web fonts and fallback stack

## 5. Imagery & Photography
- Photography style guidelines
- Iconography style and library
- Illustration style (if applicable)

## 6. Applications
- Digital templates (social, web, email)
- Print templates (cards, letterhead)
- UI components (buttons, forms, cards)

## 7. Voice & Tone (link to tone-of-voice skill)
```
