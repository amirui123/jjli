Installation & Init

npm install uisfx

import { createUISFX } from 'uisfx'

// 1. Initialiser le player
const ui = createUISFX({
  pack: 'minimal', // ou 'soft', 'arcade', 'glass', etc.
  volume: 0.7,
  enabled: true
})

// 2. Déverrouiller au 1er clic de l'utilisateur
window.addEventListener('pointerdown', () => {
  ui.unlock()
}, { once: true })

One-Shots & Boucles (Loops)

// Son ponctuel (One-shot)
ui.play('success')
ui.play('delete')
ui.play('toggle-on')

// Boucle continue (State loop)
const loop = ui.play('processing')

// Arrêt de la boucle quand le state se termine
loop?.stop()

// Changement de thème sonore instantané
ui.setPack('arcade')

Binding déclaratif HTML (bindUISFX)

import { bindUISFX } from 'uisfx'

// Attache les événements automatiquement
bindUISFX(document, { pack: 'minimal' })

// Dans votre HTML :
<button data-uisfx="success">Enregistrer</button>
<button data-uisfx="delete">Supprimer</button>
<button data-uisfx-hover="hover">Survol</button>
